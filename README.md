## 🚀 Selected Work

- [**Alpha Dawg**](https://github.com/elbarroca/ETH_Global_Cannes_2026): Multi-agent marketplace prototype with immutable agent versions, wallet identity, verified delivery paths, and canonical receipts. Placed second in two ETHGlobal Cannes bounty tracks and won $3,500.
- [**YooseAI Algarve**](https://github.com/elbarroca/Algarve_Hack): Portuguese-first housing workflow built with Python, FastAPI, and Next.js for listing search, data enrichment, mapping, and asynchronous AI phone negotiation through REST endpoints.
- [**Symphony (La Musa)**](https://github.com/elbarroca/La_musa_hack): Multi-agent RAG risk-analysis application using LangGraph, LangChain, OpenAI, and Chroma, with document upload, vector search, streaming output, and an executive dashboard.
- [**SaaS Starter**](https://github.com/elbarroca/SignUp_SaaS_Template): Next.js SaaS foundation with Supabase Auth, Stripe Checkout, webhooks, and dashboard flows.
